# 🧠 MoodLens Lab — локальный анализ эмоционального тона

![WPF](https://img.shields.io/badge/UI-WPF-0B6B60)
![License](https://img.shields.io/badge/license-MIT-5B6E69)
![Privacy](https://img.shields.io/badge/data-local_only-2B9E7A)

MoodLens Lab — автономная Windows-программа 🖥️ для учебного распознавания эмоционального тона текста. Это портфолио-проект школьника: модель, интерфейс и импорт данных работают локально 🔒 и не требуют аккаунтов или внешних сервисов.

Приложение специально не подключается к Telegram и не запрашивает логин, пароль, API ID или код подтверждения.

## ✨ Возможности

- 💬 демонстрационный чат с готовыми примерами;
- 📥 импорт обезличенного CSV, TXT, Telegram JSON или HTML;
- 😊 шесть категорий: радость, грусть, злость, тревога, удивление и нейтральный тон;
- 📊 уверенность модели и распределение эмоций;
- 🔒 обработка только в памяти компьютера;
- 🚫 никакой регистрации, сервера и отправки сообщений.

## 🚀 Быстрый старт

1. Скачайте готовую Windows-сборку из раздела **Releases** или соберите проект из исходников.
2. Запустите `MoodLensLab.exe`.
3. Нажмите **Демонстрационный чат**, чтобы сразу увидеть результат.
4. Для своих данных выберите **Экспортировать чат** и укажите CSV/TXT/`result.json`/`messages.html`.

## 📄 Формат CSV

Минимальный вариант:

```csv
text
Я очень рад этой новости!
Мне тревожно перед экзаменом
Сегодня обычный день
```

Для будущего обучения можно добавить столбец label. Используйте только собственные или синтетические сообщения.

## 🗂️ Структура проекта

```text
EmotionAnalyzer.cs       # Multinomial Naive Bayes и эмоциональные признаки
MessageData.cs           # демо-данные и локальный CSV-парсер
MainWindow.xaml          # интерфейс WPF
MainWindow.xaml.cs       # состояние окна и сводная статистика
tests/                   # smoke-тесты шести эмоциональных классов
```

## 🛠️ Запуск из исходников

Нужен [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0):

```powershell
dotnet run
```

## 📦 Готовая Windows-версия

Распакуйте `MoodLens-Lab-Windows-x64.zip` и запустите `MoodLensLab.exe`. Установка .NET не требуется.

## ✅ Проверка модели

```powershell
dotnet run --project tests/TelegramMood.SmokeTests
```

## 🔧 Технологии

- C# и WPF;
- .NET 9;
- Multinomial Naive Bayes;
- локальный CSV-парсер без внешних зависимостей.

## 🏷️ Интерактивная разметка

Откройте `labeler.html` в браузере, выберите эмоцию для каждого сообщения и нажмите **Скачать CSV**. Галочки работают прямо в браузере, а данные остаются на компьютере.

## 🧪 Обучающая выборка

Раунды калибровки добавляют трудные нейтральные и конфликтные случаи, чтобы снизить ложные срабатывания. Сеть и Telegram-аккаунт для обучения не нужны.

## ⚠️ Ограничения

Модель учебная: она может ошибаться при сарказме, сленге, отрицаниях и смешанных эмоциях. Результат нельзя считать психологической диагностикой.

## 🔐 Почему без Telegram

Проект сознательно не подключается к личным чатам и не запрашивает Telegram-коды. Это снижает риск для аккаунта и уважает ограничения Telegram API на использование данных платформы в AI/ML-системах.
