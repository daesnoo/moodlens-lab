# MoodLens Lab — локальный анализ эмоционального тона

![.NET](https://img.shields.io/badge/.NET-9.0-512BD4?logo=dotnet&logoColor=white)
![WPF](https://img.shields.io/badge/UI-WPF-0B6B60)

![Privacy](https://img.shields.io/badge/data-local_only-2B9E7A)

MoodLens Lab — автономная Windows-программа для учебного распознавания эмоционального тона текста. Это портфолио-проект школьника: модель, интерфейс и импорт данных работают локально и не требуют аккаунтов или внешних сервисов.

Приложение специально не подключается к Telegram и не запрашивает логин, пароль, API ID или код подтверждения. Это важно: актуальные Telegram API Terms запрещают использовать данные Telegram для обучения, улучшения или развёртывания AI/ML-моделей.

## Возможности

- демонстрационный чат с готовыми примерами;
- импорт обезличенного CSV, TXT, Telegram JSON или HTML;
- шесть категорий: радость, грусть, злость, тревога, удивление и нейтральный тон;
- уверенность модели и распределение эмоций;
- обработка только в памяти компьютера;
- никакой регистрации, сервера и отправки сообщений.

## Быстрый старт

1. Скачайте готовую Windows-сборку из раздела **Releases** или соберите проект из исходников.
2. Запустите `MoodLensLab.exe`.
3. Нажмите **Демонстрационный чат**, чтобы сразу увидеть результат.
4. Для своих данных выберите **Экспортировать чат** и укажите CSV/TXT/`result.json`/`messages.html`.

## Формат CSV

Минимальный вариант:

```csv
text
Я очень рад этой новости!
Мне тревожно перед экзаменом
Сегодня обычный день
```

Можно добавить второй столбец с ручной меткой для будущего обучения:

```csv
text,label
Я очень рад этой новости!,joy
Мне тревожно перед экзаменом,fear
Сегодня обычный день,neutral
```

Экспорт Telegram Desktop в `JSON` или `HTML` тоже читается локально: приложение берёт только текст сообщений и не сохраняет исходный файл. Используйте такие данные только при наличии права на их обработку и с согласия участников.

Перед импортом удалите имена, телефоны, адреса, ссылки и другие личные сведения. Используйте только собственные или синтетические сообщения.

## Интерактивная разметка

Откройте `labeler.html` в браузере, выберите эмоцию для каждого сообщения и нажмите **Скачать CSV**. Полученный файл можно открыть в MoodLens Lab. Галочки и выборы работают прямо в браузере, а данные остаются на компьютере.

## Обучающая выборка

В `data/moodlens-labeled-52.csv` сохранена базовая локальная выборка из 52 синтетических сообщений, а остальные CSV-файлы содержат дополнительные примеры для уточнения «Удивления», «Тревоги» и «Грусти». Раунды калибровки специально добавляют трудные нейтральные и конфликтные случаи, чтобы снизить ложные срабатывания. При запуске приложение автоматически добавляет все девять выборок к базовым примерам наивного байесовского классификатора. Сеть и Telegram-аккаунт для обучения не нужны.

## Ограничения

Модель учебная: она может ошибаться при сарказме, сленге, отрицаниях и смешанных эмоциях. Результат нельзя считать психологической диагностикой.

## Почему без Telegram

Проект сознательно не подключается к личным чатам и не запрашивает Telegram-коды. Это снижает риск для аккаунта и уважает ограничения Telegram API на использование данных платформы в AI/ML-системах.
